LinguaCheck

Multilingual UI regression testing for mobile eServices · Noel Jeffrey Narala Thomas

Apps for migrant workers are offered in several languages, but UI tests usually run in English only. A button that fits "Confirm booking" can clip the same label in Tamil. LinguaCheck measures how many layout bugs English-only testing misses, and the cheapest way to catch them.

15/24seeded defects caught by English-only tests
23/24caught by adding pseudo-localisation
0/8false alarms on harmless changes
Try the demo →Switch languages and apply seeded bugs to see what breaks. Read the results →Strategy comparison, screenshots and limitations. Source code →Python + Playwright harness, test checks and CI workflow.

Demo only. Not affiliated with any government agency. No real user data is collected or stored, and the name field is never submitted anywhere. Translations are machine-generated and unreviewed.
